# 자료 모아보기 페이지

D-7부터 단톡방에 드린 자료 7개 + 완주 선물 1개를 한 페이지에서 보는 모아보기입니다.

## 파일 구성

```
├─ index.html              ← 화면 엔진 (기수가 바뀌어도 수정 X)
├─ config.js               ← 제목·날짜·자료 내용·링크 전부 여기서 수정
├─ images/
│   ├─ banner.jpg          ← 상단 타이틀 이미지
│   ├─ profile.jpg         ← 프로필 사진 (배너에서 잘라낸 것)
│   ├─ thumb-05.jpg / thumb-07.jpg   ← 프드프 영상 썸네일
│   └─ review-*.jpg        ← 후기 링크 카드 썸네일
├─ files/
│   └─ month100-summary.pdf   ← 완주 선물 PDF (파일 자체에 비밀번호 걸림)
├─ .nojekyll
└─ README.md
```

## GitHub Pages로 올리기

1. GitHub에서 새 저장소(repository)를 만듭니다. (Public 저장소면 PDF도 공개되지만, 비밀번호가 걸려 있어 괜찮습니다)
2. 이 폴더의 파일과 폴더를 전부 업로드합니다 (Add file → Upload files, 폴더째 드래그).
3. Settings → Pages → Branch 를 `main` / `/ (root)` 로 선택하고 Save.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 으로 열립니다.
5. 카톡 미리보기 이미지를 확실히 띄우려면 index.html 상단 `og:image` 를 배포 주소 기준 절대경로로 바꿔주세요.
   예) `https://<아이디>.github.io/<저장소이름>/images/banner.jpg`

## 영상 재생 방식

| 영상 | 방식 | 이유 |
|---|---|---|
| ④ 체험단으로 사는 하루 (YouTube) | 페이지 안에서 바로 재생 | 유튜브는 외부 사이트 임베드 허용 |
| ⑤ 수강생 인터뷰 / ⑦ 자청 인터뷰 (프드프) | 썸네일 + 큰 버튼 → 새 창 | 프드프 영상(Cloudflare Stream)이 프드프 도메인에서만 재생되게 막혀 있음 |

프드프 쪽에서 Cloudflare Stream 영상 설정의 '허용 도메인(Allowed Origins)'에
`<아이디>.github.io` 를 추가해 주면, config.js 에서 ⑤⑦의 `type: "link"` 를 `type: "cloudflare"` 로
바꾸는 것만으로 페이지 안 재생이 됩니다. (영상 ID는 이미 `cloudflareId` 에 넣어둠)

## 기수 바꿀 때 (config.js 만)

- `cohortId` : 기수 이름. 바꾸면 "공감(다 봤어요)" 체크가 새로 시작됩니다.
- `lecture.date / time / joinOpenTime` : 특강 날짜·시각·입장 링크 공개 시각 (한국 시간)
- `lecture.joinUrl` : 넣으면 18:50부터 '입장하기' 버튼이 자동으로 생깁니다.
- `cta.url`, `links[].url` : 비어 있으면 "링크 준비 중"으로 표시됩니다.
- `guide` : ⏱ 시간 / 🎯 오늘 라이브 연결 / 👀 여기만 보세요 / ✅ 오늘 바로. 비우면 그 줄은 안 보입니다.
- 문장 안 `**굵게**`, `==형광펜==` 사용 가능.

## 미리보기 / 유입 구분

- `?now=2026-10-13T18:55` : 그 시각(KST) 기준 화면으로 보기. 18:50 입장 안내, 19:00 라이브 중 화면 점검용
- `?d=d0` : 단톡방 공지별로 붙여두면 모든 측정 이벤트에 src 로 같이 기록됩니다

## 페이지 기능

- 첫 화면: 배너 이미지 + 큰 롤링 카운트다운(초 진행 바) + 입장 안내. 18:50이 되면 안내가 초록으로 바뀌고, 19:00부터 "LIVE 진행 중"으로 전환
- 한눈에 보기: 자료 8개를 썸네일 타일로. 누르면 해당 자료로 이동. date 가 오늘인 자료에 NEW 자동 표시
- 강사 소개: 사진 + 숫자 (사전 전자책 7쪽 기준)
- 첫 진입 애니메이션 + 스크롤 시 섹션이 부드럽게 나타남 (움직임 줄이기 설정 존중)
- ② 전자책은 구글 드라이브 미리보기로 페이지 안에서 바로 읽기 가능
- "어떻게 보면 되나요" 탭 (추천 자료 강조 / 5분 모드는 "여기만 보세요" 강조)
- 봤어요 체크 + 진행도. 링크/영상을 열면 자동 체크, 브라우저에 저장
- 카운트다운 → 18:50 입장 안내 → 라이브 중 → 종료 자동 전환
- 링크 저장(복사), 캘린더 등록(.ics)
- 측정 훅: dataLayer / gtag / fbq 로 resource_open, video_play, route_select, item_check, preview_open, calendar_add, link_copy 전송
